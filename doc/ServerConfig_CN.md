# 服务端配置说明

## 概述

本文档说明 RarityCore 模组的服务端配置选项。服务端配置控制影响服务器端稀有度数据处理和同步的行为。

## 配置文件位置

服务端配置文件位于：
```
config/raritycore/server.json
```

## 配置选项

### checkVanillaRarity
- **类型**: 布尔值
- **默认值**: `true`
- **说明**: 控制是否检查原版物品稀有度并映射到 RarityCore 的稀有度系统
- **效果**: 启用时，具有原版稀有/史诗品质的物品将自动分配对应的 RarityCore 稀有度等级

### skipUnconfiguredItems
- **类型**: 布尔值
- **默认值**: `false`
- **说明**: 控制是否跳过处理没有稀有度配置的物品
- **效果**: 启用时，在渲染和同步过程中将忽略没有显式稀有度配置的物品

## 配置文件格式

```json
{
  "checkVanillaRarity": true,
  "skipUnconfiguredItems": false
}
```

## 加载优先级

服务端配置按以下顺序加载：
1. 内置默认值
2. `server.json` 文件（如果存在）

## 命令

可以通过命令管理服务端配置：

### 重新加载服务端配置
```
/reload
```
此命令重新加载所有服务端配置，包括稀有度数据。

### 查看当前配置
可以通过各种模组命令查看当前配置状态。

## 最佳实践

1. **性能考虑**：
   - 在大型整合包中启用 `skipUnconfiguredItems` 以提高性能
   - 如果想要完全控制所有稀有度分配，请禁用 `checkVanillaRarity`

2. **多人游戏服务器**：
   - 服务端配置影响所有连接的客户端
   - 更改需要服务器重启或重新加载才能生效
   - 调整这些设置时要考虑玩家体验

3. **配置管理**：
   - 修改前备份配置文件
   - 先在单人游戏中测试更改
   - 为服务器管理员记录任何自定义配置

## 故障排除

### 常见问题

1. **配置未生效**
   - 确保服务器已重启或重新加载
   - 检查配置文件的文件权限
   - 验证 JSON 语法是否正确

2. **性能问题**
   - 尝试启用 `skipUnconfiguredItems`
   - 监控服务器日志中的配置相关警告

3. **意外行为**
   - 检查配置值是否为有效的布尔值
   - 验证配置文件是否在正确位置
   - 确保没有冲突的模组修改稀有度行为

## 迁移说明

如果从这些设置还在客户端配置中的旧版本升级：
- 这些设置已从 `client.json` 移动到 `server.json`
- 旧的客户端配置文件将自动清除这些设置
- 将创建新的服务端配置文件并使用默认值
